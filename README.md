# 립모션 로봇수술 시뮬레이션 체험 (Leap Surgery Sim)

립모션(Leap Motion) 손 트래킹으로 **양손 레이저 도구를 조작**해 3D 장기를 실제로 갈라내고 봉합하는 교육용 웹 데모입니다. (Vite + Three.js)

- **오른손 집게(핀치) → 빨강 레이저 절개**
- **왼손 집게(핀치) → 파랑 레이저 봉합**
- 평소엔 **초록 레이저로 조준 미리보기**, 확실히 핀치하면 발사
- 절개 시 메시가 실제로 갈라지고, 봉합 시 아물며 바늘땀 생성

자세한 기획·구현 내용은 [`docs/PRD.md`](docs/PRD.md) 참고.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173/ 접속. 하단에서 **립모션 / 마우스 / 자동 시연** 모드 전환.
- 립모션 없이 테스트: **마우스** 모드(좌클릭=절개, 우클릭=봉합) 또는 `?mock`(가짜 손).

## 립모션 연동 (실기기)

1세대 오리지널 컨트롤러 기준:
1. **Leap Motion Orion 4.1.0** 설치.
2. Leap Control Panel → **"Allow Web Apps(웹앱 허용)" 체크** → 웹소켓(`ws://127.0.0.1:6437`) 활성화.
3. 앱에서 **"립모션" 모드** 선택 → 상태 배지가 "립모션 연결됨"이 되면 손으로 조작.

> Gemini V5는 웹소켓을 기본 제공하지 않으므로(브리지 필요) 이 데모는 Orion 4.1 웹소켓을 사용합니다.

## 3D 모델 배치

사실적 장기 모델은 라이선스·용량 문제로 저장소에 포함하지 않습니다.
[`public/models/README.md`](public/models/README.md)를 참고해 GLB를 직접 배치하세요(없으면 절차적 위장으로 폴백).
